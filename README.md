# command-line-helper

Type what you want in plain English and get a shell command, generated by a local Ollama model. It runs entirely offline.

```
❯ :: kill whatever is running on port 3000      ← press Enter
❯ kill $(lsof -ti :3000)                        ← Enter runs it · Tab clears it · or edit it first
```

It covers zsh/macOS, python, conda, docker, git, file and search commands.

## Install

```sh
./install.sh        # checks curl/jq/ollama, pulls the model, adds a `source` line to ~/.zshrc
source ~/.zshrc
```

Requires `ollama serve` to be running.

## Keys

| Key | When | Action |
|-----|------|--------|
| Enter | line starts with `::` | generate the command and put it on the line |
| Enter | generated command shown | run it (it goes into history as the real command) |
| Tab | generated command shown | clear it |
| Tab | otherwise | normal completion |

The generated command is shown in cyan. Potentially destructive commands are shown in **red** with a warning: `rm -rf`, `sudo`, force push, `reset --hard`, prune and similar. Nothing runs without your Enter.

## Config

Set these before the `source` line in `~/.zshrc`:

| Variable | Default | |
|---|---|---|
| `CLH_MODEL` | `qwen2.5-coder:1.5b` | any Ollama model |
| `CLH_URL` | `http://localhost:11434` | Ollama server |
| `CLH_PREFIX` | `::` | trigger prefix |
| `CLH_TIMEOUT` | `30` | seconds |
| `CLH_WARM` | `1` | preload the model in the background when a shell starts |

## Choosing a model

Measured on an M-series Mac with `tests/eval.sh` (25 requests):

| Model | Correct | Latency (warm) |
|---|---|---|
| `qwen2.5-coder:1.5b` (default) | ~21/25 | ~0.3s |
| `qwen3.5:4b` | ~24/25 | ~4s |

`qwen2.5-coder:3b` is a reasonable middle ground. To compare models: `CLH_MODEL=<model> ./tests/eval.sh`.
